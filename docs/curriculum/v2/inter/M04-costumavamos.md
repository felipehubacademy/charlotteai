# Module M04 — Costumávamos

> **Level**: Inter (B1)
> **Block**: B1 Block
> **Units**: 5 (I01–I05)
> **Theme**: Used to + would (past habits and states no longer true)
> **Module goal**: Student uses "used to" for past habits/states and "would" for repeated past actions in narrative.
> **Connects to**: M05 (Phrasal verbs essenciais).

## Module chunks introduced (~20)

- I used to + base / She used to + base
- I didn't use to + base
- Did you use to + base?
- I would + base (narrative habits)
- when I was a child / in the old days

## Unit I01 — I used to be different

> **Sub-CEFR**: B1 | **Grammar focus**: Used to (positive, habit/state)
> **Markers**: [denso]
> **Real-life context**: You describe how things used to be in your childhood or before.

### 1. Grammar (10 exercises)

1. **multiple_choice** — "I _____ play soccer every day."
   **Options**: used to / use to / am used to
   **Answer**: used to
   **Explanation**: "Used to + base" for past habit no longer done.

2. **multiple_choice** — "She _____ live in NYC."
   **Options**: used to / use to / is used to
   **Answer**: used to
   **Explanation**: Same form for all persons: "used to live".

3. **word_bank** — "We _____ go to the beach every summer."
   **Choices**: used to / use to / are used to / didn't use to
   **Answer**: used to
   **Explanation**: "We used to go" — past habit.

4. **word_bank** — "He used to _____ tall."
   **Choices**: be / is / was / been
   **Answer**: be
   **Explanation**: After "used to", base form: "be" (not "is" or "was").

5. **fill_gap** — "I used _____ play piano."
   **Hint**: particle between used and verb
   **Answer**: to
   **Explanation**: "Used TO + base verb": "used to play".

6. **fill_gap** — "She _____ to read every night."
   **Hint**: form of "use" with -d
   **Answer**: used
   **Explanation**: "Used to" — spelled "used" (with d) regardless.

7. **fill_gap** — "We used to _____ in Rio."
   **Hint**: base verb "live"
   **Answer**: live
   **Explanation**: After "used to", base form: "live".

8. **fix_error** — "I used to playing soccer."
   **Hint**: After used to, base form (not -ing)
   **Answer**: I used to play soccer.
   **Explanation**: After "used to", BASE form, not -ing. "Used to play".

9. **fix_error** — "She used to lived here."
   **Hint**: After used to, base
   **Answer**: She used to live here.
   **Explanation**: After "used to", base form "live", not "lived".

10. **read_answer**
    **Passage**: "I used to play soccer every weekend. My sister used to dance. We used to go to the beach every summer. Now things are different."
    **Question**: What did the sister use to do?
    **Answer**: dance (or "used to dance")
    **Explanation**: The text says "My sister used to dance".

## Unit I04 — Used to vs Would

> **Sub-CEFR**: B1 | **Grammar focus**: Distinguish used to (states + actions) from would (actions only)
> **Markers**: [denso]
> **Real-life context**: You choose correctly between both for narratives.

### 1. Grammar (10 exercises)

1. **multiple_choice** — "She _____ tall when she was young." (state)
   **Options**: used to be / would be / was use to
   **Answer**: used to be
   **Explanation**: For STATES (be, have, like), use "used to", not "would".

2. **multiple_choice** — "Every summer, we _____ go camping." (action)
   **Options**: would / used to / would be
   **Answer**: would
   **Explanation**: For repeated ACTIONS, both work, but "would" is great with "every".

3. **word_bank** — "I _____ love that song." (past state/feeling)
   **Choices**: used to / would / am used to / would be
   **Answer**: used to
   **Explanation**: For "love" (feeling), use "used to". Not "would love" (which means "would like" in conditional).

4. **word_bank** — "My grandpa _____ tell us stories." (action)
   **Choices**: would / used to / both work
   **Answer**: would
   **Explanation**: For repeated past action narrative, "would" works (used to also works).

5. **fill_gap** — "I _____ live in Rio."
   **Hint**: state (live) — used to
   **Answer**: used to
   **Explanation**: "Used to live" — state. Not "would live".

6. **fill_gap** — "We _____ go fishing every weekend."
   **Hint**: repeated action with "every"
   **Answer**: would (or "used to")
   **Explanation**: Repeated action with "every" — "would go" works perfectly.

7. **fill_gap** — "She _____ be very shy as a kid."
   **Hint**: state (be) — used to
   **Answer**: used to
   **Explanation**: For "be + adj" (state), only "used to".

8. **fix_error** — "I would have a red bike."
   **Hint**: have = state, use "used to"
   **Answer**: I used to have a red bike.
   **Explanation**: "Have" (own) is state — use "used to have", not "would have".

9. **fix_error** — "He would like cartoons."
   **Hint**: like = state/feeling
   **Answer**: He used to like cartoons.
   **Explanation**: "Like" is state/feeling — use "used to", not "would" (which changes meaning).

10. **read_answer**
    **Passage**: "I used to be shy. We would visit my aunt every Sunday. She used to live nearby. We would play games together."
    **Question**: Where did the aunt use to live?
    **Answer**: nearby
    **Explanation**: The text says "She used to live nearby".
