# Charlotte Curriculum v2 — Master Index

> **Decisão arquitetural**: 2026-05-14
> **Total**: 72 módulos · 336 unidades · CEFR A1 → C2

- Cada linha = um arquivo de módulo
- Status mostra completude
- Sessões futuras: leiam **este arquivo + `STYLE-GUIDE.md` + `TEMPLATE.md` + `novice/M01-ola-mundo.md`** antes de escrever módulos
