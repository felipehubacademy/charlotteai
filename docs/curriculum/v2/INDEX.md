# Charlotte Curriculum v2 — Master Index

> **Decisão arquitetural**: 2026-05-14 (revisado 2026-05-31 com Fase B)

> **Estrutura padrão**: 5 unidades por módulo. Alguns módulos têm 6ª unidade quando o tema pede (M05/M18/M19/I05/I22/A11).
> **IDs locais**: N01–N06 / I01–I06 / A01–A06
> **Methodology**: Lexical Approach (Michael Lewis) + PPP + Communicative Approach + Spiral Review
> **Activities per unit**: Grammar · Listening/Speaking · Role-play · Guided Chat

## Como usar este index

- Cada linha = um arquivo de módulo
- Status mostra completude (apenas após `compile-curriculum-v2.mjs` passar OK)
- Fonte da verdade pedagógica: `grammar-progression.md` (temas + grammar permitida por módulo)
- Antes de escrever: leia **AUTHORING-GUIDE.md + grammar-progression.md + STYLE-GUIDE.md + novice/M01-ola-mundo.md**

## Convenções de arquivo

- Nome: `{level}/M{NN}-{slug-kebab-case}.md` (ex: `novice/M02-meu-mundo.md`)
- IDs de unit dentro do módulo: **sempre** `{LETRA}01..{LETRA}05` onde LETRA = N/I/A
- Ao terminar um módulo: rodar `node apps/mobile/scripts/compile-curriculum-v2.mjs` e atualizar status aqui pra `done`.
