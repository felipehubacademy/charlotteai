# Module M21 — Se isso, então aquilo

> **Level**: Novice (A2)
> **Block**: A2 Block
> **Units**: 5 (N01–N05)
> **Theme**: First conditional (If + present, will + base)
> **Module goal**: Aluno sai sabendo formar primeira conditional pra situações reais futuras possíveis.
> **Connects to**: M22 (Conexões) — depois das condicionais, aprende conectores e adverbs of manner.

## Module chunks introduced (~20)

- If + present simple, will + base
- If it rains, I'll stay home.
- If she comes, we'll have dinner.
- What will you do if...?
- I'll help if you need.
- Unless = If not
- I'll go unless it rains.

## Unit N01 — Se chover, eu fico

> **Sub-CEFR**: A2 | **Grammar focus**: First conditional (basic structure)
> **Markers**: [denso]
> **Real-life context**: Você fala sobre o que vai fazer dependendo do tempo, agenda, decisão.

### 1. Grammar (10 exercises)

1. **multiple_choice** — "If it _____, I'll stay home."
   **Options**: rains / will rain / rained
   **Answer**: rains
   **Explanation**: First conditional: "If + present simple, will + base". A parte do "if" usa PRESENTE: "If it rains".

2. **multiple_choice** — "If she comes, we _____ have dinner."
   **Options**: will / would / are
   **Answer**: will
   **Explanation**: Após if + present, usa "will + base" na consequência. "We will have" / "we'll have".

3. **word_bank** — "I _____ call you if I have time."
   **Choices**: will / would / can / am
   **Answer**: will
   **Explanation**: "I'll call you" — consequência futura. Will + base.

4. **word_bank** — "If you _____ early, you'll see the sunrise."
   **Choices**: wake up / will wake up / woke up / wakes up
   **Answer**: wake up
   **Explanation**: "If + present simple" — verbo base com you. "If you wake up early".

5. **fill_gap** — "If it _____ sunny, we'll go to the beach."
   **Hint**: Verbo "to be" presente em condição
   **Answer**: is
   **Explanation**: "If it IS sunny" — present simple na cláusula if.

6. **fill_gap** — "If she _____, I'll call her back."
   **Hint**: Present simple 3ª pessoa de "call"
   **Answer**: calls
   **Explanation**: "If she calls" — 3ª pessoa + -s no present.

7. **fill_gap** — "We _____ travel if we save money."
   **Hint**: Consequência futura
   **Answer**: will
   **Explanation**: "We will travel" — will + base na consequência.

8. **fix_error** — "If it will rain, I'll stay."
   **Hint**: Cláusula if NÃO usa will
   **Answer**: If it rains, I'll stay.
   **Explanation**: "If" usa PRESENTE, não will. "If it rains", não "If it will rain". Will só na consequência.

9. **fix_error** — "If she comes, we have dinner."
   **Hint**: Consequência precisa de will
   **Answer**: If she comes, we'll have dinner.
   **Explanation**: Consequência futura precisa de WILL. "We'll have dinner", não "we have".

10. **read_answer**
    **Passage**: "If it rains tomorrow, I'll stay home. If it's sunny, we'll go hiking. If she comes, we'll have lunch together."
    **Question**: What will the speaker do if it's sunny?
    **Answer**: go hiking
    **Explanation**: O texto diz "If it's sunny, we'll go hiking".

### 2. Listening/Speaking (5 phrases)

1. **"If it rains, I'll stay home."** — weather conditional
2. **"If she comes, we'll have dinner."** — person conditional
3. **"I'll call you if I have time."** — order reversed
4. **"If you wake up early, you'll see the sunrise."** — invitation/promise
5. **"We'll travel if we save money."** — life goal conditional

## Unit N04 — A menos que

> **Sub-CEFR**: A2 | **Grammar focus**: Unless (= if not)
> **Markers**: —
> **Real-life context**: Você expressa condições negativas com "unless" em vez de "if not".

### 1. Grammar (10 exercises)

1. **multiple_choice** — "I'll go _____ it rains."
   **Options**: unless / if / when
   **Answer**: unless
   **Explanation**: "Unless" = "if not" / "a menos que". "I'll go unless it rains" = irei a menos que chova.

2. **multiple_choice** — "She'll come _____ she's busy."
   **Options**: unless / if / when
   **Answer**: unless
   **Explanation**: "Unless she's busy" = se ela não estiver ocupada.

3. **word_bank** — "We'll leave _____ you want to stay."
   **Choices**: unless / if not / when not / but
   **Answer**: unless
   **Explanation**: "Unless you want to stay" = "if you don't want".

4. **word_bank** — "I _____ call you unless you ask me not to."
   **Choices**: will / would / can / am
   **Answer**: will
   **Explanation**: Consequência com unless: usa will + base.

5. **fill_gap** — "I'll meet you _____ you're late."
   **Hint**: A menos que (a alternativa de "if not")
   **Answer**: unless
   **Explanation**: "Unless you're late" = se você não estiver atrasado.

6. **fill_gap** — "She _____ come unless she's sick."
   **Hint**: Auxiliar futuro
   **Answer**: will
   **Explanation**: "She will come unless..." — will + base.

7. **fill_gap** — "Unless _____ rains, we'll go to the park."
   **Hint**: Sujeito impessoal
   **Answer**: it
   **Explanation**: "Unless it rains" — sujeito "it" pra clima.

8. **fix_error** — "I'll go unless it doesn't rain."
   **Hint**: Unless já é negativo
   **Answer**: I'll go unless it rains.
   **Explanation**: "Unless" já tem sentido negativo (=if not). NÃO usar "unless + not" — é dupla negativa.

9. **fix_error** — "I'll go if not it rains."
   **Hint**: Forma natural
   **Answer**: I'll go unless it rains.
   **Explanation**: "If not" em uma frase é comum, mas "unless" é mais natural pra essa construção.

10. **read_answer**
    **Passage**: "I'll come to the party unless I'm tired. We'll go hiking unless it rains. I'll cook dinner unless you want pizza."
    **Question**: When won't the speaker come to the party?
    **Answer**: if I'm tired
    **Accepts**: tired
    **Explanation**: O texto diz "I'll come unless I'm tired" — significando que não virá se estiver cansado.

### 2. Listening/Speaking (5 phrases)

1. **"I'll go unless it rains."** — basic unless
2. **"She'll come unless she's busy."** — person + unless
3. **"We'll leave unless you want to stay."** — group + unless
4. **"I'll call unless you ask me not to."** — preference unless

## Unit N05 — Vida real condicional

> **Sub-CEFR**: A2 | **Grammar focus**: Integration first conditional + unless
> **Markers**: —
> **Real-life context**: Você combina condicionais variadas pra discutir vida real.

### 1. Grammar (10 exercises)

1. **multiple_choice** — "If I _____ time, I'll exercise."
   **Options**: have / will have / had
   **Answer**: have
   **Explanation**: If + presente.

2. **multiple_choice** — "I _____ call you if it rains."
   **Options**: will / would / am
   **Answer**: will
   **Explanation**: Consequência futura: will.

3. **word_bank** — "We'll travel _____ we save money."
   **Choices**: if / unless / when / so
   **Answer**: if
   **Explanation**: "If we save" — condição positiva.

4. **word_bank** — "I'll come _____ I'm sick."
   **Choices**: unless / if / when / before
   **Answer**: unless
   **Explanation**: "Unless I'm sick" = a menos que esteja doente.

5. **fill_gap** — "If she _____ early, we'll have time."
   **Hint**: Present simple 3ª pessoa "arrive"
   **Answer**: arrives
   **Explanation**: 3ª pessoa: arrives.

6. **fill_gap** — "I'll go to the gym _____ I'm too tired."
   **Hint**: A menos que
   **Answer**: unless
   **Explanation**: Unless = if not.

7. **fill_gap** — "What _____ you do if it rains?"
   **Hint**: Auxiliar futuro
   **Answer**: will
   **Explanation**: "What will you do?" — WH futuro.

8. **fix_error** — "If it will rain, I'll stay home."
   **Hint**: Cláusula if sem will
   **Answer**: If it rains, I'll stay home.
   **Explanation**: "If + present", não will.

9. **fix_error** — "I will come unless it doesn't rain."
   **Hint**: Unless já é negativo
   **Answer**: I'll come unless it rains.
   **Explanation**: Unless + presente afirmativo. Sem "unless + not".

10. **read_answer**
    **Passage**: "If it's sunny tomorrow, I'll go to the beach. If it rains, I'll stay home. I'll meet my friend unless she cancels."
    **Question**: When won't the speaker meet the friend?
    **Answer**: if she cancels
    **Accepts**: she cancels
    **Explanation**: O texto diz "unless she cancels" — significando que não vão se encontrar se ela cancelar.

### 2. Listening/Speaking (5 phrases)

1. **"If I have time, I'll exercise."** — positive condition

## Cross-unit consolidation

Ao terminar M21, o aluno deve usar naturalmente:
- First conditional: If + present, will + base
- Both orders: "If X, I'll Y" / "I'll Y if X"
- Unless = if not (sem dupla negativa)
- WH-questions: What will you do if...?
- Variedade de contextos: tempo, dinheiro, humor, pessoas

Esses chunks abrem M22 — fechamento do Novice com conectores e adverbs of manner.
